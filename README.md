# Гурт «Грим та Грім»

Адаптивний landing page для тестового завдання на позицію Content Manager / Junior Front-End у Lotoplay.

## Технології

- HTML5
- CSS3
- CSS custom properties для стандартизації кольорів, відступів, заокруглень і переходів
- Адаптивна верстка через media queries

JavaScript у першому етапі реалізації не використовується: навігація, базова перевірка форми та переходи між секціями виконані засобами HTML/CSS.

## Як запустити

1. Завантажити або розпакувати проєкт.
2. Відкрити файл `index.html` у браузері.

Додаткові команди для запуску не потрібні.
